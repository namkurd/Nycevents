# NYC Events

Personal NYC events calendar for two people, shared as a claude.ai artifact page.

- **The plan is `PLAN.md`.** Read it before doing anything. Work one milestone at a time and stop at each gate.
- Run in the **NYC Events** cloud environment; its network allows the source hosts.
- Never invent events, times or prices. Every event links back to a fetched source.
- No Claude API key and no `@anthropic-ai/sdk`.
- **This repo is public.** Never commit the owner's home location, nearby routes, or anything derived from them. They come from the `NYC_HOME_*` environment variables only. `dist/` and `data/curated/one-seat-stops.json` stay gitignored.
- Ask the owner before creating scheduled tasks or sharing the page. Open no PR unless asked.
